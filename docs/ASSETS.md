# Third-party assets

Every asset in this repo that was not made for it, with where it came from, its licence and what it is used for.
Original game content is never listed here because it is never committed (see README.md).

## Surfaces and sky (Tools/Import, Content/OpenSCCT/ThirdParty)

All of these are CC0 1.0 (public domain dedication): no attribution is required, it is given anyway.
`Tools/Import/pbr_sets.json` is the machine-readable copy of this list (exact download URLs);
`Tools/Import/Import-Assets.ps1` downloads, packs and imports them.

### ambientCG (https://ambientcg.com, CC0 1.0)

2K JPG sets. Each is packed into two textures under `Content/OpenSCCT/ThirdParty/ambientCG/`:
`T_<Set>_N` (its DirectX normal map) and `T_<Set>_ORD` (R ambient occlusion, G roughness re-centred on 0.5,
B colour brightness re-centred on 0.5). They are the world-aligned DETAIL layer of `M_ScctSurface`: the original
texture keeps the colour, the set adds close-up normal, roughness and occlusion. The surface class that uses each
set is in `Tools/Import/surface_classes.json`.

### Poly Haven (https://polyhaven.com, CC0 1.0)

4K HDRI panoramas under `Content/OpenSCCT/ThirdParty/PolyHaven/`, each with a 1K `_light` copy (moon disc clamped)
that the level's sky light uses. Which map gets which sky is in `Tools/Import/map_skies.json`.

| HDRI | Page | Used for |
|---|---|---|
| kloppenheim_02_puresky | https://polyhaven.com/a/kloppenheim_02_puresky | clear night sky with a moon |
| kloppenheim_07_puresky | https://polyhaven.com/a/kloppenheim_07_puresky | overcast night sky |
| qwantani_dusk_2_puresky | https://polyhaven.com/a/qwantani_dusk_2_puresky | dusk sky (ClubE) |

### Made here

`Content/OpenSCCT/Materials/T_WaterNormal` (water ripples) is generated by `Tools/Import/fetch_assets.py`; the
stars of `M_ScctSky` are drawn by the material. Neither comes from a download.
